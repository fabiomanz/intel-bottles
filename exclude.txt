# Formulae never to build, and any root whose chain needs one of them.
#
# qtwebengine cannot finish inside GitHub's 6-hour job ceiling (measured: cut off at
# 5h50m). Excluding it also skips qt, pyside and qtwebview, which depend on it -- without
# this they would each spend ~6 hours rebuilding it before failing the same way.

qtwebengine

# qtquick3d fails to configure on Intel: the formula deletes Qt's bundled assimp and
# forces -DFEATURE_system_assimp=ON, but Homebrew's assimp is 6.0.5 and Qt 6.11's probe
# fails against it (QT_FEATURE_quick3d_assimp=ON, TEST_quick3d_assimp=FALSE).
# Upstream has an arm64_tahoe bottle for the same version, so this is Intel-only bit-rot
# -- nothing tests x86_64 since Homebrew moved it to Tier 3. Remove this line once the
# formula or assimp is fixed.
qtquick3d

# qt3d hits the same assimp incompatibility directly rather than through qtquick3d
# (QT_FEATURE_qt3d_assimp=ON, TEST_assimp=FALSE). The formula even applies an
# assimp-6.patch, which does not fix the x86_64 configure. Remove when upstream does.
qt3d

# openssl@1.1 was retired from homebrew-core and can never be rebuilt. It is still
# installed locally (and pinned), so the local planner resolves it while CI reports it
# missing. Excluding keeps the two consistent.
openssl@1.1

# llvm (23.x) does not fit in a GitHub job either. Measured twice, 2026-09-30 and
# 2026-10-01: cut off at 350 minutes both times, still in the third of its three build
# phases (stage 1 ~1h35m, stage 2 ~1h35m, then the runtimes). It made every scheduled run
# since 2026-09-17 end "cancelled" and held its wave open for six hours each day.
# llvm@22 is a single-stage build (~3-4h) and stays in -- rust and most llvm users only
# need that. Excluding llvm also skips deno (build dependency) and yt-dlp (needs deno).
# To bottle it, assign it to "selfhosted" in runners.json and remove this line.
llvm
